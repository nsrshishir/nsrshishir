# Project Overview

This directory contains a personal portfolio website for Niaj Shishir, an Odoo & Full Stack Developer. The website showcases his skills, experience, and projects in a static HTML format.

# Key Files

*   `index.html`: The main entry point of the website. It integrates various sections including Home, About Me, My CV, My Projects, and Contact.
*   `CV.html`: Likely an alternative or supplementary HTML version of the CV.
*   `cv_ats.html`: Another alternative, possibly an ATS (Applicant Tracking System)-friendly HTML version of the CV.
*   `image_niaj_blue_suit.jpeg`: A personal image of Niaj Shishir used prominently on the "About Me" section.
*   `img/`: This directory contains various images that are used throughout the "My Projects" section to visually represent different development projects and integrations.
*   `.git/`: This directory indicates that the project is managed using Git for version control.

# Usage

To view this portfolio website, simply open the `index.html` file in any modern web browser. Since it is a static website, no local server setup or complex build process is required.
